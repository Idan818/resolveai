# ResolveAI V2 - Interactive Prompt Playground

This portfolio prototype demonstrates:
- AI workflow design
- Prompt architecture
- Editable system prompts and constraints
- Structured output contracts
- Grounding and guardrails
- Human approval gates
- Prompt quality evaluation
- Safe production architecture thinking

The Prompt Playground is an interactive local prototype. It does not expose an API key in the browser.
A production implementation would call an LLM through a secure backend.

## Run
Open index.html in a browser.

## GitHub Pages
Create a separate repository named `resolveai`, upload `index.html`, and enable GitHub Pages from the main branch / root.
